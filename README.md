# Personal Dashboard

A private, cloud-synced dark-mode personal productivity dashboard built with plain HTML, CSS, and JavaScript — backed by **Firebase Authentication** and **Cloud Firestore**, and hosted on **GitHub Pages**.

## Features

- **Private Sign-In Gate** — Locked behind Firebase Email & Password authentication (no public sign-ups).
- **Real-Time Cloud Sync** — Tasks, daily focus, quick links, scratchpad notes, and settings sync instantly across devices via Cloud Firestore, protected by user-scoped Security Rules.
- **Dynamic Greeting & Live Clock** — Switch between 12-hour and 24-hour time, plus a **Main Focus for Today** tracker.
- **Live Weather** — Powered by [Open-Meteo](https://open-meteo.com/) (no API key needed) with °C/°F toggle, city search, and geolocation.
- **Focus Timer (Pomodoro)** — 25m Focus / 5m Short Break / 15m Long Break circular timer with a gentle audio chime.
- **To-Do List, Quick Links & Scratchpad** — Priority flags, task progress bar, auto-favicons, word counter, and JSON backup/restore.
