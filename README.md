# Personal Dashboard

A clean, modern dark-mode daily productivity dashboard built with plain HTML, CSS, and JavaScript — zero build tools required and ready to host for free on **GitHub Pages**.

## Features

- **Dynamic Greeting & Live Clock** — Switch between 12-hour and 24-hour time, plus a **Main Focus for Today** tracker.
- **Live Weather** — Powered by [Open-Meteo](https://open-meteo.com/) (no API key needed) with °C/°F toggle, city search, and geolocation.
- **Focus Timer (Pomodoro)** — 25m Focus / 5m Short Break / 15m Long Break circular timer with a gentle audio chime.
- **To-Do List** — Add tasks, flag high-priority items, filter by All / Active / Done, and track completion progress.
- **Quick Links** — Pin your favorite websites with automatic favicons.
- **Scratchpad Notes** — Auto-saving notes with word/character count and one-click copy.
- **Customizable & Private** — Choose from 5 accent colors, export/import backups, and keep all personal data strictly in your browser's `localStorage`.

## Publishing on GitHub Pages

1. Push this folder to a GitHub repository.
2. Open your repository on GitHub and go to **Settings → Pages**.
3. Under **Build and deployment → Branch**, select **`main`** and folder **`/ (root)`**, then click **Save**.
4. After ~1 minute, your dashboard will be live at `https://<your-username>.github.io/<repo-name>/`.
